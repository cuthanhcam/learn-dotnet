# Dynamic Programming & Backtracking
This project contains solutions for dynamic programming and backtracking problems in C#.

## Problems
1. **Climbing Stairs**: Find the number of ways to climb n stairs.
2. **Combination Sum**: Find all combinations that sum to a target.

## How to Run
1. Navigate to `DynamicProgramming` folder.
2. Run `dotnet run` to execute `Program.cs`.
