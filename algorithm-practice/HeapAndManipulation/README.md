# Heap & Manipulation
This project contains solutions for heap-based problems in C#.

## Problems
1. **Kth Largest Element**: Find the kth largest element in an array.
2. **Top K Frequent Elements**: Find the k most frequent elements in an array.

## How to Run
1. Navigate to `HeapAndManipulation` folder.
2. Run `dotnet run` to execute `Program.cs`.
