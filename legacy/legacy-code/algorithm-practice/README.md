# Algorithm Practice
This repository contains C# solutions for algorithmic problems, organized by data structure and algorithm type. Each folder is a separate project with complete programs and documentation.

## Projects
1. **ArraysAndStrings**: Problems related to arrays and strings.
2. **LinkedLists**: Problems related to linked lists.
3. **StacksAndQueues**: Problems related to stacks and queues.
4. **TreesAndGraphs**: Problems related to trees and graphs.
5. **DynamicProgramming**: Problems related to dynamic programming and backtracking.
6. **HeapAndManipulation**: Problems related to heaps and priority queues.

## How to Run
1. Navigate to a specific project folder (e.g., `ArraysAndStrings`).
2. Run `dotnet run` to execute the `Program.cs` file.
3. Check the `README.md` in each folder for details on the problems and solutions.
