# Stacks & Queues
This project contains solutions for stack and queue problems in C#.

## Problems
1. **Valid Parentheses**: Check if a string of parentheses is valid.
2. **Implement Queue using Stacks**: Implement a queue using two stacks.

## How to Run
1. Navigate to `StacksAndQueues` folder.
2. Run `dotnet run` to execute `Program.cs`.
